# Cars Dealership Full-Stack Development Capstone

## Repository Name
cars-dealership-fullstack-capstone

## Project Name
Cars Dealership Full-Stack Development Capstone Project

## Project Description
This project is a full-stack web application for a car dealership business. It allows users to view dealership locations, explore dealer details, register and log in, and submit reviews about dealerships.

## Technologies Used
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django and REST APIs
- Database: SQLite and MongoDB
- Deployment and DevOps: Docker, Kubernetes, GitHub Actions, IBM Cloud Code Engine

## Main Features
- Display dealership locations and details
- Filter dealerships by state
- User registration, login, and logout
- Submit and view dealership reviews
- Sentiment analysis of customer reviews
- Responsive web interface

## Purpose
The purpose of this project is to demonstrate full-stack development, API integration, database management, version control, CI/CD, and application deployment.
